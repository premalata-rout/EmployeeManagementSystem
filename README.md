# Employee Management System

A Java-based Employee Management System developed using JDBC and PostgreSQL. This project performs CRUD operations to manage employee records in a database.

## Technologies Used
- Java
- JDBC (Java Database Connectivity)
- PostgreSQL
- SQL
- IntelliJ IDEA

## Features
- **Insert:** Add new employee records.
- **Update:** Update existing employee details.
- **Delete:** Delete employee records.
- **Fetch:** Retrieve employee information from the database.

## Project Structure
- `Driver` – Provides the main method and menu-driven interface.
- `Entity` – Contains the Employee entity class and its data.
- `Service` – Contains the business logic and database operations.

## Database
- Database: PostgreSQL
- Table: `employe`

## How to Run
1. Install Java JDK and PostgreSQL.
2. Create the required database and employee table.
3. Configure the database URL, username, and password.
4. Add the PostgreSQL JDBC driver to the project.
5. Run the `Driver` class.
6. Select an operation from the menu.

## Learning Outcomes
- Understanding JDBC connectivity.
- Performing CRUD operations using SQL.
- Connecting Java applications with PostgreSQL.
- Organizing Java code into separate packages.
